# Audio-Intelligence.md &mdash; audit 2026-08-02

## Verified (spot checks that held)

- The shipped Audio Intelligence job runs VAD, alignment, speech markers, prosody, and room tone, including requested feature subsets: `src/services/audio/intelligence/audioIntelligenceTypes.ts`, `src/stores/timeline/clip/clipAudioIntelligenceActions.ts`, and `src/services/aiTools/definitions/analysis.ts`.
- The pinned Silero model is `v5.1.2`, with an exact URL, SHA-256, and cache version: `src/services/audio/intelligence/audioIntelligenceModelCatalog.ts` and `src/services/audio/intelligence/audioIntelligenceTypes.ts`.
- Source-time artifacts carry source fingerprints, analyzer versions, stale state, and optional clip-audio-state hashes: `src/services/audio/audioArtifactTypes.ts` and `src/services/audio/intelligence/audioIntelligencePersistence.ts`.
- Speech markers support breaths, fillers, repetitions, false starts, and long pauses; `getSpeechMarkers` supplies bounded, filterable source/timeline-time results and a prosody summary: `src/services/audio/speechMarkersManifest.ts`, `src/services/audio/intelligence/speechMarkers/fillerDetection.ts`, and `src/services/aiTools/handlers/speechMarkers.ts`.
- The four listed AI tools are registered and implemented. `findSilentSections` uses VAD, then live RMS, then transcript gaps and returns `detectionSource`: `src/services/aiTools/definitions/analysis.ts`, `src/services/aiTools/handlers/timelineHandlerRegistry.ts`, and `src/services/aiTools/handlers/clipSilence.ts`.
- The Analysis overview has Audio/sparkline and Markers/needles lanes; the Action Center exposes current audio-job progress, run/cancel, and marker count; the settings component shows per-feature artifact ages and run/re-run/cancel: `src/components/panels/properties/analysisWorkspace/analysisOverviewPainter.ts`, `src/components/panels/properties/AnalysisTab.tsx`, `src/components/panels/properties/AnalysisAudioSettings.tsx`, and `src/components/panels/properties/useAnalysisAudioIntelligence.ts`.
- Editing uses a fresh source VAD artifact before RMS fallback, falls back to `-60 dB` when no overlapping loudness curve is available, snaps with a 10 ms limit when decode succeeds, and prefers a fresh room-tone profile: `src/services/audio/intelligence/audioEditDetectionArtifacts.ts` and `src/stores/timeline/audioEdit/audioDetectionActions.ts`.

## Outdated or wrong (claim &rarr; reality, with file evidence)

- "The feature has eight connected capabilities" implied that loudness and onset analysis are Audio Intelligence stages: the job has five stages only: `vad`, `alignment`, `speech-markers`, `prosody`, and `room-tone`. Loudness and onset are separate companion generators whose artifacts are consumed by the feature. Evidence: `src/services/audio/intelligence/audioIntelligenceTypes.ts`, `src/stores/timeline/clip/clipAudioIntelligenceActions.ts`, `src/services/audio/LoudnessEnvelopeGenerator.ts`, and `src/services/audio/BeatOnsetAnalysisGenerator.ts`.
- The introduction claimed use by "kernel story moments," and the prosody row claimed "kernel emphasis evidence": this client repository has no code that supports either claim; current client-side prosody use is settings/Analysis UI, while the Agent Timeline payload loader does not load a prosody payload. Evidence: `src/components/panels/properties/useAnalysisAudioIntelligence.ts` and `src/services/agentTimeline/artifacts/audioIntelligencePayloadLoader.ts`.
- "Nearest channel-zero crossing": the snap implementation explicitly uses channel index `0`, not a search across channels. Evidence: `src/services/audio/intelligence/audioEditDetectionArtifacts.ts` and `src/services/audio/sampleAccurateSnap.ts`.
- The source list omitted the separate loudness/onset generators and the zero-crossing implementation that underpin documented behavior. Evidence: `src/services/audio/LoudnessEnvelopeGenerator.ts`, `src/services/audio/BeatOnsetAnalysisGenerator.ts`, and `src/services/audio/sampleAccurateSnap.ts`.

## Noteworthy / unusual

- `loadAudioIntelligencePayloads` decodes only loudness, onsets, VAD, and speech markers. Prosody and room-tone metadata are read through separate direct paths, so the common name is broader than the loader's actual payload coverage: `src/services/agentTimeline/artifacts/audioIntelligencePayloadLoader.ts`, `src/services/aiTools/handlers/speechMarkers.ts`, and `src/services/audio/intelligence/audioEditDetectionArtifacts.ts`.
- The default UI run requests all five stages, but alignment may be skipped without a transcript and speech-marker filler detection may be skipped while breath detection remains available: `src/services/audio/intelligence/AudioIntelligenceGenerator.ts`.
- The Analysis Audio lane can use a prosody artifact's `energy-rms-db` curve as a fallback/alternate source in addition to a loaded loudness curve; this is shipped behavior not previously mentioned by the document: `src/components/panels/properties/useAnalysisAudioIntelligence.ts`.
