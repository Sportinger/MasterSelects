# Dissolve Transitions

Soft transitions that let one shot melt into the next instead of cutting.

## Crossfade
![The harbour image dissolving into the stage image at 0 %, 25 %, 50 %, 75 % and 100 %](assets/transitions/crossfade.webp)

The first clip fades out while the next one fades in, so for a moment you see
both. The calm, classic way to soften a cut or to show that time has passed.
- **Duration** – how long the blend takes, 2 seconds by default. You can also drag the edge of the transition in the timeline.
- **Include audio** – blends the sound of the two clips as well. For now this is heard during playback only; an exported file still cuts the sound at the edit.

Tip: titles, logos and keyed clips dissolve cleanly too: the old one fades away while the new one appears over whatever lies below.
