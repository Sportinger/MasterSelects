MasterSelects is a browser-based media editor and an agent-friendly foundation
for creative tools. Edit video, mix audio, animate graphics, build 3D scenes,
and work with live visuals in one workspace with WebGPU rendering.

Run it locally from source to build new effects, panels, and workflows with
your coding agent while working on your project. Contribute useful additions
so other people and their agents can build on them. The interface is optimized
for touch and iPad; phone workflows are still being refined.

Read [about MasterSelects](/about/), start with the
[documentation overview](/docs/getting-started/overview/), or
[open the editor](https://www.masterselects.com/editor).
