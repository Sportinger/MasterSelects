MasterSelects is a browser-based WebGPU compositor and media editor with
timeline editing, nested compositions, motion design, an audio workstation,
and AI-assisted workflows.

Start with the [documentation overview](/docs/getting-started/overview/) or
[open the editor](https://www.masterselects.com/editor).

## Highlights

<CardGrid stagger>
  <Card title="Timeline editing" icon="setting">
    Multi-track NLE timeline with clips, keyframes, masks, nested
    compositions, and a global graph editor.
  </Card>
  <Card title="Motion design" icon="star">
    Shape layers, appearance stacks, GPU-instanced replicators with
    modifiers and falloffs, expressions, presets, and templates.
  </Card>
  <Card title="WebGPU engine" icon="rocket">
    Real-time compositing, effects, and export on your GPU — preview and
    export share one evaluated frame model.
  </Card>
  <Card title="AI-assisted workflows" icon="open-book">
    Semantic AI tools for every editing capability, from clip creation to
    motion templates.
  </Card>
</CardGrid>
